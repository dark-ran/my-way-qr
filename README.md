# 내 방식 QR

불편을 평소 말로 표현하면 기기 안의 AI가 9개 접근성 설정으로 바꿔 개인정보 없는 QR에 담고, 어느 키오스크든 그 QR로 내 방식 화면이 되는 시제품입니다. 2026 AI 라이프 솔루션 챌린지 출품작(아이디어 챌린지 수상 후보작 「내 방식 QR」 구현).

- 체험: https://dark-ran.github.io/my-way-qr/ (시연용 모의 키오스크, 실제 결제·발급 없음)
- 키오스크 연동: `<script src="myway.js"></script>` 한 줄. 주소의 `#p=` 값을 읽어 화면 전체에 적용합니다.
- 프로필 규격: 9개 설정을 비트로 묶어 36진수로 적습니다. 개인정보는 없습니다.

## AI
1단계는 글자 조각 해시 선형 모델(`model.json`, 197KB), 2단계는 Xenova/paraphrase-multilingual-MiniLM-L12-v2(q8, 약 118MB) 임베딩 위 선형 머리(`head.json`)입니다. 추론은 전부 브라우저에서 합니다.

## 성능
| 평가 | 결과 |
|---|---|
| AI 작성 평가 240문장(학습 미사용) | F1 0.83 |
| 실제 기사·논문 발언 60건 | F1 0.52, 학습 반영 5겹 교차검증 0.54 |

학습 데이터는 합성 문장입니다. `train/`에 생성·학습·측정 코드와 평가셋이 있습니다. 실사용자 실험은 아직 하지 않았습니다.
